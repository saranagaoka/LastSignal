# LastSignal

A cinematic first-person story prototype built with React Three Fiber and Three.js.

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown by Vite. Choose **Enter the District**, then click to enable pointer lock. Use **WASD** to move, the mouse to look, and **Shift** to run.

## Included

- First-person pointer-lock controls
- Procedural streets and open-world layout
- Walkable-size buildings and an emergency shelter
- Animated NPCs walking through the district
- Atmospheric lighting, sky, fog, stars, bloom, grain, and vignette
- Story presentation with HUD and objectives
